# Aspirin

Rural-first browser health coach for lifestyle-disorder awareness (diabetes, hypertension, and prevention-focused habits).

## What it does

- Shows a QR code for easy mobile access.
- Collects first-time health profile details and gives an initial health score.
- Highlights prevention-oriented recommendations aligned to practical Indian rural context.
- Lets users submit daily healthy actions and get a daily habit score.
- Supports optional integration with a free AI API endpoint for additional guidance.

## Run locally

1. Open `/tmp/workspace/nimilsalam/Aspirin/index.html` in a browser.
2. Or serve with a static server of your choice.
